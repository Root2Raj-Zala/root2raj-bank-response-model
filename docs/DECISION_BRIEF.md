# Decision brief

The top-ranked tenth contains 51.8% positives, compared with 30.8% across the test cohort. It captures only 16.8% of all test positives. This does not mean contacting those people would cause that outcome: the records were already produced by a campaign process.

The primary conclusion is a deployment gate: useful ranking is insufficient when cohort prevalence, feature availability and entity independence remain unresolved. Report all these issues with the result rather than substituting high training accuracy.

Interview explanation: I removed the tempting call-duration input because it arrives after the call. I kept selection, calibration and evaluation on separate chronological blocks and surfaced the distribution change. The implementation was AI-assisted.
